# Lenar Domingo — Portfolio

Personal portfolio site for Lenar Domingo, a UI/UX designer, frontend developer and B.S. Computer Science graduate of Saint Louis University.

**Live site:** https://domingolenar.github.io/Domingo-Portfolio/

## Tech stack

- [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- [Tailwind CSS 4](https://tailwindcss.com/)
- [React Router](https://reactrouter.com/)
- [Lucide](https://lucide.dev/) and [React Icons](https://react-icons.github.io/react-icons/)
- [Web3Forms](https://web3forms.com/) for the contact form
- Deployed to GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`)

## Running locally

```bash
npm install
npm run dev      # start the dev server
npm run lint     # run ESLint
npm run build    # production build into dist/
npm run preview  # serve the production build
```

Pushing to `main` builds and deploys the site automatically.
